# PreCare Mobile App (Dành Cho Thai Phụ)

Mobile application scaffold for pregnant women to track fetal growth trajectories, view simplified checkup summaries, receive appointment reminders, and access verified paraclinical reports.

## Features
- **Hồ Sơ Thai Kỳ**: Gestational age tracker & EDD countdown.
- **Nhật Ký Cân Nặng & Chỉ Số**: Simplified centile growth tracking.
- **Báo Cáo Cận Lâm Sàng**: View verified ultrasound & paraclinical reports (PDF).
- **Thông Báo & Tái Khám**: Push notifications for checkups and medication.

## Architecture
- React Native / Expo scaffold.
- REST API connection to PreCare FastAPI Gateway (`/api/v1/auth`, `/api/v1/records`).
